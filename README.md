# ქალაქობანა — ინდივიდუალური ვებ-თამაში 🇬🇪

სრულფასოვანი, სწრაფი და დახვეწილი ქართული სამაგიდო თამაშის „ქალაქობანა“ ვებ-ვერსია ერთი მოთამაშისთვის ხელოვნური ინტელექტის მქონე ვირტუალური ბოტების წინააღმდეგ.

თამაში მუშაობს **100% ლოკალურად და ოფლაინ რეჟიმში ბრაუზერში** — არანაირი სერვერი, რეგისტრაცია, ავტორიზაცია, მონაცემთა ბაზის სერვერი ან გარე ბიბლიოთეკა (Zero Dependencies).

🌐 **ონლაინ ვერსია (Live Demo):** [https://kalakobana-snowy.vercel.app](https://kalakobana-snowy.vercel.app)

## 🚀 გაშვების გზები

თამაშის გაშვება შესაძლებელია ორივე გზით:

### 1. პირდაპირი გაშვება (Double Click / `file://`)
* გახსენით ფაილი `dist/index.html` პირდაპირ ნებისმიერ ბრაუზერში (Safari, Chrome, Firefox, Edge).
* `dist/index.html` არის ერთიანი (Single-File) ავტონომიური bundle (ზომა ~800 KB), რომელიც შეიცავს მთელ HTML-ს, CSS სტილებს, აუდიო სინთეზატორს, სათამაშო ლოგიკას და 4,200+ ქართულ სიტყვას.

### 2. ლოკალური ვებ-სერვერით (PWA და Service Worker მხარდაჭერით)
```bash
# Python-ით
python3 -m http.server 8000

# ან Node-ით
npx serve .
```
გახსენით `http://localhost:8000` ბრაუზერში. აპლიკაცია ავტომატურად დაარეგისტრირებს Service Worker-ს (`sw.js`) და იმუშავებს როგორც სრულფასოვანი PWA (შესაძლებელია ტელეფონის ეკრანზე დაყენება "Add to Home Screen").

## 🎯 თამაშის წესები და ქულების სისტემა

რაუნდის დაწყებისას ალგორითმი ირჩევს ქართული ანბანის ერთ-ერთ ასოს (ალბათობების გათვალისწინებით). მოთამაშემ დროის ამოწურვამდე (ნაგულისხმევად 90 წამი) უნდა შეავსოს აქტიური კატეგორიები ამ ასოზე დაწყებული სიტყვებით.

### ქულების დარიცხვა (კლასიკური წესები):
* **20 ქულა:** მხოლოდ ერთმა მოთამაშემ დაწერა სწორი პასუხი ამ კატეგორიაში (სხვებმა ვერ შეავსეს ან შეეშალათ).
* **10 ქულა:** რამდენიმე მოთამაშემ დაწერა სწორი პასუხი, მაგრამ ყველამ *განსხვავებული* სიტყვა.
* **5 ქულა:** ორ ან მეტ მოთამაშეს დაემთხვა ერთი და იგივე სიტყვა (ან სინონიმი/ალიასი).
* **0 ქულა:** ველი ცარიელია ან სიტყვა არასწორია.
* **+5 ქულა (ბონუსი):** მოთამაშეს, რომელიც დროის ამოწურვამდე დააჭერს ღილაკს „დავასრულე“ და ექნება სწორი პასუხების უმრავლესობა.

## ✨ ძირითადი ფუნქციონალი და ტექნოლოგიური უპირატესობები

1. **ჭკვიანი AI მოწინააღმდეგეები (ბოტები):**
   * 6 განსხვავებული ბოტი: გიორგი, ნინო, დათო, მარიამი, ლუკა, ანა.
   * 3 სირთულის დონე: მარტივი (Easy, შევსება 60-75%), საშუალო (Medium, შევსება 80-90%), რთული (Hard, შევსება 95-99%).
   * პოპულარობის ფილტრი (1-5): მარტივი ბოტები ირჩევენ გავრცელებულ სიტყვებს, რთული ბოტები კი იშვიათ და უცნობ ცნებებს.
   * შეუძლებელი კომბინაციების გათვალისწინება (მაგ. ქვეყანა ასოებზე „ღ“, „ძ“, „ჭ“ არ არსებობს).

2. **მრავალმხრივი ვალიდაცია:**
   * **მკაცრი (Strict):** სიტყვა უნდა იძებნებოდეს ბაზაში ან მომხმარებლის ლექსიკონში.
   * **თვითდადასტურება (Self-confirmation):** უცნობი სიტყვების შემთხვევაში რაუნდის ბოლოს ჩნდება ფანჯარა, სადაც შეგიძლიათ დაადასტუროთ სიტყვა და სურვილისამებრ დაამატოთ თქვენს პირად ლექსიკონში.
   * **თავისუფალი (Free):** მიიღება ნებისმიერი სიტყვა სწორი საწყისი ასოთი.
   * დუბლიკატების კონტროლი (ერთსა და იმავე რაუნდში ერთი სიტყვის გამოყენება სხვადასხვა კატეგორიაში იზღუდება).
   * ქართული ტექსტის სრული ნორმალიზაცია (მთავრული ასოების მხედრულში გარდაქმნა, ბრჭყალების, ტირეების და აპოსტროფების გასუფთავება).

3. **მობილურზე ოპტიმიზაცია (Mobile UX):**
   * ფიქსირებული ტაიმერი და ქულების პანელი.
   * ვირტუალური კლავიატურისგან დაცვა: `visualViewport` API, `scrollIntoView({ block: 'center' })` ველზე ფოკუსირებისას.
   * `100dvh` განლაგება და Safe Area Insets (iOS Safari / Android Chrome).
   * არანაირი ჰორიზონტალური სქროლი 320px-დან 1920px-მდე.

4. **Web Audio API ხმოვანი ეფექტები:**
   * 100% სინთეზირებული ჟღერადობა (წიკწიკი ბოლო 5 წამზე, ტაიმერის ამოწურვის ზუმერი, ქულების გამოცხადება, გამარჯვების ფანფარი).
   * ხმის ჩართვა/გამორთვის (Mute) ღილაკი.

5. **პირადი ლექსიკონი და სტატისტიკა:**
   * მომხმარებლის მიერ საკუთარი სიტყვების დამატება და წაშლა.
   * ლექსიკონის ექსპორტი და იმპორტი JSON ფორმატში.
   * თამაშების, მოგებების, მაღალი ქულების და საყვარელი ასოების დეტალური სტატისტიკა (`localStorage`).
   * სესიის აღდგენა (`sessionStorage`) შემთხვევითი რეფრეშის შემთხვევაში („გსურთ გაგრძელება?“).
